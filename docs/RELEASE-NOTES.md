Julia's Launcher 0.3.15: a new look.

- New design by Cyanexani: a deep plum theme with a butter-yellow accent, pill buttons, a new Play page (your hardware as chips, a "Ready to play" line, the engine as two buttons, options in three columns with their description, the activity log folded until you open it) and a new Hardware & ID page (cards instead of plain text, rounded charts, your PC highlighted). Every button still does what it did.
- Updates install more safely: every file is checked again just before it is installed, the old launcher is put back if a copy fails, and a version already installed is not downloaded again.
- Setup: the progress bar no longer lands on the first step after the page was scrolled.
