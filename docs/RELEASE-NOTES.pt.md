Julia's Launcher 0.3.22: acabou o ciclo de crashes no primeiro arranque de uma versão, e o teu preset fica o teu.

- O primeiro arranque de uma versão nova aquece e recomeça uma vez. Quando esse arranque crashava, todos os seguintes eram outra vez de aquecimento e crashavam igual (uma RX 7600 nove vezes seguidas). Agora um aquecimento que falha logo não volta a ser pedido: o arranque seguinte é normal.
- As definições automáticas já não mudam o teu preset sempre que o launcher abre: é escolhido uma vez num PC novo, outra vez só se a placa gráfica ou a memória mudarem, ou quando carregas em "Automatico para este PC". A 0.3.21 podia passar para Ultra baixo um PC que jogava bem noutro preset; se te aconteceu, escolhe o teu preset outra vez uma vez.
