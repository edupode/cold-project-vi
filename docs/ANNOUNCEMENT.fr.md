## Julia's Launcher 0.3.26 est sortie 🛠️

**Correctifs**
🎯 Le jeu **ne se ferme plus une seconde après le démarrage avec le DLSS en pleine résolution** (DLAA : Net, cgbj classique, certains Personnalisés). C'était le crash le plus fréquent : le DLAA tourne maintenant en DLSS Qualité.
📦 **Avertissement de jeu incomplet :** le lanceur compare ton dossier du jeu avec le jeu complet et te dit ce qui manque avant de jouer.

**Nouveau**
🌍 **Choix de la langue**, maintenant avec **Español**. Tu veux le lanceur dans ta langue ? Les traductions sont de simples fichiers que tout le monde peut ajouter : voir CONTRIBUTING.md.
🔒 Les logs des parties sont maintenant lus par edupode **et l'équipe du projet** ; si tu avais dit oui, le lanceur te redemande une fois.

**Installation**
🔄 En 0.3.x : rien à faire, elle s'installe toute seule dans les 5 minutes, jeu fermé.
📥 Nouveau ou sur un ancien launcher : télécharge **VI-Setup-0.3.26.exe** sur https://github.com/felicienradio/cold-project-vi/releases/latest et lance-le.
