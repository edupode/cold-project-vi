## Julia's Launcher 0.3.20 est sortie 🧩

**Correctifs**
🧩 Le jeu se ferme tout de suite avec « code 1 » ? Le lanceur **nomme maintenant le fichier du jeu manquant** (par exemple amd_fidelityfx_loader_xbox.dll) avant JOUER. Copie-le depuis le paquet complet du jeu à côté du .exe du jeu.
🔁 Un fichier du jeu manquant ne fait plus passer les cartes AMD sur un autre moteur.

**Installation**
🔄 En 0.3.x : rien à faire, elle s'installe toute seule dans les 5 minutes, jeu fermé.
📥 Nouveau ou sur un ancien launcher : télécharge **VI-Setup-0.3.20.exe** sur https://github.com/felicienradio/cold-project-vi/releases/latest et lance-le.
