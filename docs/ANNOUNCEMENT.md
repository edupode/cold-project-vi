## Julia's Launcher {tag} is out 🛠️
**Fixes**
🎯 The game **no longer closes a second after starting with DLSS at full resolution** (DLAA: Sharp, Classic cgbj, some Custom presets). It was the most common crash: DLAA now runs as DLSS Quality.
📦 **Incomplete game warning:** the launcher checks your game folder against the complete game and tells you what is missing before you play.

**New**
🌍 **Language picker**, now with **Español**. Want the launcher in your language? Translations are simple files anyone can add: see CONTRIBUTING.md.
🔒 Game logs are now read by edupode **and the project's team**; if you said yes before, the launcher asks you once more.

**Install**
🔄 On 0.3.x: nothing to do, it installs itself within 5 minutes while the game is closed.
📥 New here or on an older launcher: download **VI-Setup-{version}.exe** from https://github.com/felicienradio/cold-project-vi/releases/latest and run it.
