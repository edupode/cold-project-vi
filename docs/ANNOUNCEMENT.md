## Julia's Launcher {tag} is out 🚀
**More FPS**
⚡ **Ultra Low and Modest PC run faster:** the game's own shadows and far detail are made lighter before it starts (from VIctory-Hydra). Want it on another preset? Tick **Lighter game detail** in the launch options.
💪 **Beefy PC mode** (was "Recommended") keeps the game's full detail.

**Fixes**
🎯 No more closing a second after starting with DLSS at full resolution (DLAA): it was the most common crash. DLAA now runs as DLSS Quality.
📦 **Incomplete game warning:** the launcher tells you what is missing from your game folder before you play.

**New**
🌍 **7 languages:** English, Português, Français, Deutsch, Español, Italiano, Русский. Want yours? See CONTRIBUTING.md.
🔒 Game logs are now read by edupode **and the project's team**; if you said yes before, the launcher asks you once more.

**Install**
🔄 On 0.3.x: nothing to do, it installs itself within 5 minutes while the game is closed.
📥 New here or on an older launcher: download **VI-Setup-{version}.exe** from https://github.com/felicienradio/cold-project-vi/releases/latest and run it.
